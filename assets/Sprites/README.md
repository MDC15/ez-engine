# Sprites

Finished sprite art goes here: PNG (via zigimg) or the engine's ZTEX
(`TextureData`: RGBA8/BGRA8).

- Uniform grids animate with `SpriteSheet` + `SpriteAnimation`.
- Packed art (e.g. AI sheets with drift) uses an atlas JSON sidecar next
  to the image — see `docs/superpowers/specs/2026-10-13-packed-atlas-design.md`.
- Sample art (`player_sheet.png`, `sprite.png`) is placeholder; replace it.
