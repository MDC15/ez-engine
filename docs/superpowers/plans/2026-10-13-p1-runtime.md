# P1 Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the three P1 gaps from TODO.md / docs/project-overview.md: scene→runtime pipeline, ECS lifetime rules, audio resample + device interface.

**Architecture:** Add a small pure-logic spawn helper in `src/scene/` (no texture IO inside), pin ECS memcpy semantics with docs + tests, and extend `src/audio/audio.zig` with a linear resampler plus a `Device` vtable (NullDevice for tests). No Pulse/ALSA driver in this plan.

**Tech Stack:** Zig 0.16.0, `ez_engine` lib, `zig build test`.

**Spec:** `TODO.md` (Renderer/Runtime/Library hardening sections), `docs/project-overview.md:35-43`, `template/game/src/main.zig:34-40` (manual spawn to generalize), `src/scene/scene.zig:1-86`, `src/ecs/world.zig:15-17`, `src/audio/audio.zig:88-172`.

## Global Constraints

- Zig 0.16.0 only (`build.zig.zon`, README).
- `zig build` + `zig build test` must stay green on Linux x86_64; other targets skip desktop steps with warning.
- Public API exports only via `src/root.zig`; breaking changes noted in CHANGELOG.md.
- Components remain plain data, alignment <= 16, byte-copied on migration (`src/ecs/component.zig:10-13`).
- Audio mixer stays allocation-free in `mix()`; resampling happens outside the realtime callback (existing comment in `src/audio/audio.zig:132-134`).

## Review Focus

- Scene object with `size <= 0` or NaN/Inf position must not spawn an entity — expect skip or `error.InvalidSceneObject`, never a zero-size sprite.
- Scene with unknown `version != 1` must fail with `error.UnsupportedSceneVersion`, not spawn partial entities.
- Component holding a slice/pointer is shallow-copied on `add`/migration — expect docs + test to state no destructor runs and `destroy` does not free it.
- `Audio.play` with clip rate != device rate must keep failing with `error.SampleRateMismatch` until caller resamples — expect resample helper to be the documented fix.
- Resampler with `target_rate == 0` or `channels == 0` must return an error, never divide by zero.
